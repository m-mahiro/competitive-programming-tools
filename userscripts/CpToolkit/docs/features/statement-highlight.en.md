# Statement highlighting

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](statement-highlight.md)

> Highlight numbers, variables, and the time and memory limits in a task statement.

![Statement highlighting](../images/statement-highlight.png)

## How it works

- Highlights numbers in the text and numbers and variables in formulas in the Problem Statement and Constraints sections.
- Shows the time and memory limits in a larger font. Limits of 2 sec and 1024 MiB are not emphasized by default.
- Each color can be changed in the detailed settings.

## Detailed settings

Open this feature’s “Detailed settings” in CP Toolkit.

| Setting                                     | Default   |
|---------------------------------------------|-----------|
| Number color                                | `#0033b3` |
| Variable color                              | `#9e2927` |
| Time limit color                            | `#b3542a` |
| Memory limit color                          | `#1d643b` |
| Also emphasize limits of 2 sec and 1024 MiB | Off       |
