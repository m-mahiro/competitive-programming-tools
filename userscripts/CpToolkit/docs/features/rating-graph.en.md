# Performance on the rating graph

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](rating-graph.md)

> Overlay performance from rated contests on a user's rating graph.

![Performance on the rating graph](../images/rating-graph.png)

## How it works

- View performances from rated contests on your own or another user's rating graph.
- Toggle the overlay with the performance button. Choose “all” for the full history or “recent” for the latest results.
- The default range is the last 20 contests. In the detailed settings, enter a count such as `20` or a percentage such as `50%`.

## Detailed settings

Open this feature’s “Detailed settings” in CP Toolkit.

| Setting                                                                  | Default |
|--------------------------------------------------------------------------|---------|
| Show only recent results at first                                        | On      |
| Recent range (e.g. 20 for the last 20 contests, 50% for the latest half) | `20`    |
