# 解説の一覧表示

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](editorial-list.en.md)

> 解説一覧で、各解説の本文をリンクの下に展開します。

<p><img src="../images/editorial-list.png" alt="解説の一覧表示"><br><sub>解説の一覧で、各解説の本文をリンクの下に展開した例。</sub></p>

## 使い方

- 一覧をスクロールすると、画面に入った AtCoder 内の解説をリンクの下に展開します。外部リンクやネタバレ扱いの解説は対象外です。
- 解説は0.5秒間隔で読み込みます。
