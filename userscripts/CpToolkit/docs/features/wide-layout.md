# ページ幅の拡張

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](wide-layout.en.md)

> ページ本文の表示幅を指定できます。

## 使い方

- 表示幅を `75%` や `1200px` のように指定します。空欄では AtCoder 標準の幅を使います。

## 詳細設定

設定画面でこの機能の「詳細設定」を開きます。

| 項目                                      | 既定値   |
|-------------------------------------------|----------|
| 表示幅（例：75%、1200px。空欄で標準の幅） | （空欄） |

## 動くページ

- AtCoder の各ページ（サイトのルート `/` を除く）
