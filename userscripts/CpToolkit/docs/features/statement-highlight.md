# 問題文の強調表示

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](statement-highlight.en.md)

> 問題文の数値や変数、実行時間制限とメモリ制限を強調します。

<p><img src="../images/statement-highlight.png" alt="問題文の強調表示"><br><sub>問題文の数値、変数、実行時間制限とメモリ制限を強調した例。</sub></p>

## 使い方

- 「問題文」と「制約」の本文中の数値、数式中の数値と変数に色を付けます。
- 実行時間制限とメモリ制限を大きく表示します。2 秒と 1024 MiB の制限は、既定では強調しません。
- 色は詳細設定で項目ごとに変えられます。

## 詳細設定

設定画面でこの機能の「詳細設定」を開きます。

| 項目                             | 既定値    |
|----------------------------------|-----------|
| 数字の色                         | `#0033b3` |
| 変数の色                         | `#9e2927` |
| 実行時間制限の色                 | `#b3542a` |
| メモリ制限の色                   | `#1d643b` |
| 2 秒と 1024 MiB の制限も強調する | OFF       |
