# Keyboard shortcuts

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](keyboard-shortcuts.md)

> Submit, open the settings and more with keys you choose.

![Shortcut shown on the submit button](../images/keyboard-shortcuts.png)

## How it works

- In the detailed settings, write a key for each action. Join `Ctrl`, `Shift`, `Alt` and a character or a key such as `Enter`, `Escape` or an arrow (`Left` and so on) with `+` (e.g. `Ctrl+Shift+Enter`, `Alt+S`). Case does not matter.
- Write `none` to use no key for that action.
- Leave the submit key empty to use the site default: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> on AtCoder and Codeforces, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> on AOJ and paiza, and <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>Enter</kbd> on Library Checker. yukicoder has no default key. Hover over the submit button to see the key.
- If you press the submit key while the [submission helper](java-submit.en.md) is transforming pasted code, the code is submitted after the transform finishes.
- Folding folds Java classes and multi-line comments.
- The post to X opens with the title and URL of the current page. You post it yourself from the opened page.

## Detailed settings

Open this feature’s “Detailed settings” in CP Toolkit.

| Setting                                                       | Default      |
|---------------------------------------------------------------|--------------|
| Submit (empty for the site default, none to turn it off)      | (empty)      |
| Fold Java classes and comments (none to turn it off)          | Ctrl+Shift+M |
| Open the CP Toolkit settings (none to turn it off)            | Ctrl+I       |
| Open a post to X for the current page (empty to turn it off)  | (empty)      |
