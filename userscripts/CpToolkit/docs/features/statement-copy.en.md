# Copy statement

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](statement-copy.md)

> Copy sections such as the statement and constraints individually or together.

![Copy statement](../images/statement-copy.png)

## How it works

- Choose “Copy” beside a section heading to copy that section.
- “Copy All” includes the task title, URL and all sections before the first sample in the displayed language.
- Choose Markdown or plain text in the detailed settings.
- You can also run “Copy All” with [Keyboard shortcuts](keyboard-shortcuts.en.md).

## Detailed settings

Open this feature’s “Detailed settings” in CP Toolkit.

| Setting     | Default  |
|-------------|----------|
| Copy format | Markdown |
