# Test case averages

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](average-result.md)

> Show average runtime and memory usage across test cases on the submission details page.

<p><img src="../images/average-result.png" alt="Test case averages"><br><sub>A submission detail page showing the average execution time and memory usage of the test cases.</sub></p>

## How it works

- For submissions with at least two test cases, the first row shows the number accepted out of the total, average runtime and average memory usage.
- A “+” marks a lower bound when the average includes a case that timed out.
