# Highlight hovered variables and numbers

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](variable-hover.md)

> Hover over a variable or number in a formula to highlight matching occurrences in the same task.

<p><img src="../images/variable-hover.png" alt="Highlight hovered variables and numbers"><br><sub>Hovering over a variable highlights the same variable in the task.</sub></p>

## How it works

- Matching variables or numbers stay highlighted while you hover. On printable task lists, matches are limited to the current task.
- Click to pin the highlight. Click again or press <kbd>Esc</kbd> to clear it.
- Numbers such as "998244353" and "10<sup>9</sup>" are treated as single units. A number with an exponent matches only numbers with the same exponent.
- Variables and numbers can be switched separately in the detailed settings.

## Detailed settings

Open this feature’s “Detailed settings” in CP Toolkit.

| Setting             | Default |
|---------------------|---------|
| Highlight variables | On      |
| Highlight numbers   | On      |
