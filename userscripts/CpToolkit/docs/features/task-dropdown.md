# 問題のドロップダウン

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](task-dropdown.en.md)

> 「問題」タブから各問題へ移動したり、複数の問題をまとめて開いたりできます。

![問題のドロップダウン](../images/task-dropdown.png)

## 使い方

- コンテストの「問題」タブを、各問題へ移動できるドロップダウンにします。
- 「新しいタブで開く」を選ぶと、問題を新しいタブで開きます。
- 「まとめて開く」で全問または指定した範囲を、最大20問まで一度に開けます。21問以上ある場合は範囲を選びます。逆順にも対応しています。
- 問題の一覧はコンテストごとに1回取得し、10日間記憶します。
