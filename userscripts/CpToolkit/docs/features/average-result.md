# テストケースの平均

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](average-result.en.md)

> 提出の詳細に、テストケースの平均実行時間と平均メモリ使用量を表示します。

<p><img src="../images/average-result.png" alt="テストケースの平均"><br><sub>提出の詳細に、テストケースの平均実行時間と平均メモリ使用量を表示した例。</sub></p>

## 使い方

- テストケースが2件以上あるとき、表の先頭に AC 件数／全件数、平均実行時間、平均メモリ使用量を表示します。
- TLE を含む場合は、打ち切り時点の実行時間で計算した平均に「+」が付きます。
