[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](tessoku-difficulty.md)

> Show the difficulty ratings from the book on the Tessoku task list.

<p><img src="../images/tessoku-difficulty.png" alt="Tessoku difficulty"><br><sub>Book difficulties shown in the Tessoku task list.</sub></p>

## How it works

- Each task name is prefixed with a star and its difficulty rating from the book.
- Use the sort button to switch between difficulty order and task ID order.
