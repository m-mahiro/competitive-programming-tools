# ドロップダウンをホバーで開く

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](hover-menu.en.md)

> ユーザー名や表示言語、「提出結果」にマウスカーソルを重ねると、選択肢が開きます。

![ドロップダウンをホバーで開く](../images/hover-menu.png)

## 使い方

- ヘッダーのユーザー名にマウスカーソルを重ねると、設定などの選択肢が開きます。
- コンテストページでは、表示言語から日本語と英語を、「提出結果」から「すべての提出」や「自分の提出」を選べます。
