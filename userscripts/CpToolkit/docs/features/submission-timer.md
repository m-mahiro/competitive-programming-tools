# 提出の予約

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](submission-timer.en.md)

> 指定した時間後に、エディタにあるコードを提出します。

**この機能は既定で OFF です。設定画面で有効にしてください。**

## 使い方

- 提出ボタンの横にある「提出の予約」を開き、何分後に提出するかを入力して「予約する」を押します。
- 問題ページを開いたままにすると、指定した時間後に、その時点のコードを提出します。「取り消す」を押すか、ページを閉じるか再読み込みすると、予約は解除されます。
