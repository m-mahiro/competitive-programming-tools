# Delayed submission

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](submission-timer.md)

> Submit the code in the editor after a delay you specify.

**This feature is off by default. Turn it on in the settings.**

## How it works

- Open “Delayed submission” beside the submit button, enter the delay in minutes and choose “Schedule”.
- Keep the task page open. When the timer expires, the code currently in the editor is submitted. Choose “Cancel”, close the page or reload it to clear the timer.
