# カレンダーへの登録

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](contest-calendar.en.md)

> コンテスト名と開催日時を入力した Google カレンダーの予定作成画面を開けます。

![カレンダーへの登録](../images/contest-calendar.png)

## 使い方

- 開催前または開催中のコンテストで、開催日時の横にある「カレンダーに追加」を押します。
- コンテスト名と開催日時が入力された Google カレンダーの画面が開きます。内容を確認して予定を保存します。
