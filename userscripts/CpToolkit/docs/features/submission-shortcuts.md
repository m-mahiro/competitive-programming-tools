# AC 提出へのボタン

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](submission-shortcuts.en.md)

> 問題ページから、実行時間順やコード長順などで AC 提出の一覧を開けます。

![AC 提出へのボタン](../images/submission-shortcuts.png)

## 使い方

- 問題名の横のボタンを押すと、選んだ項目で AC 提出を並べ替えた一覧が開きます。実行時間・コード長・メモリは小さい順、提出時間は古い順です。
- コンテスト中は他の人の提出を見られないので、コンテストが終わるまでボタンを出しません。
- 出すボタンは、詳細設定のチェックで選べます。1つも選ばなければ何も出しません。
- 詳細設定で言語を指定すると、その言語の提出だけに絞ります。
- [ショートカットキー](keyboard-shortcuts.md)でも、同じ一覧を新しいタブで開けます。

## 詳細設定

設定画面でこの機能の「詳細設定」を開きます。

| 項目                     | 既定値   |
|--------------------------|----------|
| 言語（空欄ならすべて）   | （空欄） |
| 実行時間順のボタンを出す | ON       |
| コード長順のボタンを出す | ON       |
| 提出時間順のボタンを出す | ON       |
| メモリ順のボタンを出す   | ON       |
