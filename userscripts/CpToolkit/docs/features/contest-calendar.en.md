# Add to calendar

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](contest-calendar.md)

> Open a Google Calendar event form with the contest name and times filled in.

<p><img src="../images/contest-calendar.png" alt="Add to calendar"><br><sub>“Add to calendar” next to the contest time. It opens the event page of Google Calendar.</sub></p>

## How it works

- On an upcoming or ongoing contest page, click “Add to calendar” beside the contest dates.
- Google Calendar opens with the contest name and times filled in. Review and save the event.
