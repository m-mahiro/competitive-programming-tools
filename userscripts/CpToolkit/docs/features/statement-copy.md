# 問題文のコピー

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](statement-copy.en.md)

> 問題文や制約などを項目ごとに、またはまとめてコピーできます。

![問題文のコピー](../images/statement-copy.png)

## 使い方

- 「Copy」は、問題文や制約などの項目を個別にコピーします。
- 問題名の横の「Copy All」は、表示中の言語の問題名・URL と、最初の入出力例より前の項目をまとめてコピーします。
- 詳細設定で Markdown またはプレーンテキストを選べます。

## 詳細設定

設定画面でこの機能の「詳細設定」を開きます。

| 項目           | 既定値   |
|----------------|----------|
| コピーする形式 | Markdown |
